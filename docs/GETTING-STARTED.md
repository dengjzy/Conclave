# Conclave 使用指南

这里提供配置说明和常用功能查阅。首次使用时，宠物会检查 Agent 是否安装、能否使用，并询问是否配置任务来源。需要重新检查时，打开左下角 **帮助 → 检查使用环境**。

## Agent 安装与登录

打开 [**设置 → 外部智能体**](conclave:settings/agents)，查看安装、启用和可用状态。Agent 可通过自己的账号或兼容的模型服务商使用；具体需求以环境检查提示为准。

![设置 → 外部智能体：装好并登录的 Agent 标着已就绪](assets/guide/agents-ready.png)

- 需要使用 Agent 自己的账号：在终端运行那一行给出的登录命令，再点 **重新检测**。
- 列在 **可安装** 里（点开它）：点 **在终端安装**，或复制安装命令自己跑，装完点 **重新检测**。
- 使用模型服务商：按下节配置兼容的服务商；已在 Agent 自己的配置中接入的，可按环境检查提示确认。

## 模型服务商

**用 Agent 自己的账号可以跳过。** 想用火山方舟、智谱 GLM、Kimi 这类编程套餐，或让 OpenCode、Pi、DeepSeek Harness 回答时才要。

![设置 → 服务商 → 添加服务商：选套餐，填 API Key](assets/guide/provider.png)

在 [**设置 → 服务商**](conclave:settings/model-providers) 点 **添加服务商**：选套餐、粘贴 API Key、勾选给哪些 Agent 用，点 **保存并测试**，每项都是 ✓ 就能用。Cursor 用不了服务商。

新建会话时在输入框的 **服务商** 里选它，按服务商计费，不占官方额度；会话开始后不能再换。

## 多个账号

**可选，** 只有 Claude Code 和 Codex 支持。

![设置 → 账号：额度用完自动换号，以及添加账号](assets/guide/accounts.png)

在 [**设置 → 账号**](conclave:settings/accounts) 点 **添加 Claude Code 账号**（或 Codex），再点 **添加并登录**，在下方终端登录后点 **设为当前**。额度用完时默认自动换到下一个账号，会话接着跑。

## 任务来源

**可选，** 要从 GitHub、Jira、Linear、禅道导入任务时才要。

![设置 → 插件 → 推荐插件](assets/guide/plugins.png)

1. 在 [**设置 → 插件**](conclave:settings/plugins) 点 **安装插件**。
2. 打开 **设置 → 集成 → 来源名称**，填站点和筛选条件，点 **登录** 填 Token，打开 **同步到收件箱**。
3. 在侧栏 **收件箱** 点 **立即同步**，选一条点 **导入任务**。

| 来源 | 需要准备 |
|---|---|
| GitHub | Personal access token、搜索条件（只看 Bug 可加 `label:bug`） |
| Jira | 站点、登录邮箱、API token、JQL |
| Linear | 个人 API Key |
| 禅道 | RESTful API v1 地址（如 `https://zentao.company.com/zentao/api.php/v1`）、Token、产品 ID |

推荐里没有的平台，可以在 **从其他位置安装** 填 GitHub 仓库或选本地 ZIP；想自己写一个，见 [插件开发指南](https://github.com/dengjzy/Conclave/blob/main/docs/PLUGINS.md)。

## 常用功能

遇到相关场景时，可以在这里查阅。

### 无缝移交

![输入框左下角的 Agent 菜单](assets/guide/handoff.png)

额度用完了，或者想换个 Agent 接着做：点输入框左下角的 Agent 名称，换一个，写句补充说明，点 **移交**。新 Agent 会带着聊天记录，在同一个目录里接着做。

### 跨会话引用

需要参考之前讨论的方案时，在输入框输入 `@`，切到 **会话**，按标题、项目或 Agent 查找并选择，再写下要做的事。当前 Agent 会按需读取被引用的历史记录，继续在当前目录工作；发送后的会话标题可点击打开原对话。

会话分类需要在 [设置 → 权限](conclave:settings/permissions) 中开启 **让 Agent 读你在 Conclave 里的记录**；开启后从 Agent 下次启动起提供读取工具，关闭后立即停止读取。移交用于换 Agent 接手当前工作，跨会话引用用于补充参考资料。

### 预约：额度恢复后或到点再发

![点时钟按钮后弹出的「预约发送」](assets/guide/schedule.png)

1. 在输入框里写好消息。
2. 点输入框右下角的 **时钟** 按钮。
3. 选 **额度恢复后**，或 **指定时间**。
4. 点 **预约**。

| 还能预约 | 在哪里 |
|---|---|
| 任务 | 任务工具栏上的时钟按钮 |
| 计划批准 | 计划卡片上的 **预约批准** |
| 查看、改时间、取消 | 状态栏的「N 个预约」，或总览的「接下来」 |

到点后，Agent 按弹窗里写的模式无人值守运行，点 **在设置里改** 可以换。电脑睡着时预约不会运行，可以打开状态栏咖啡图标的「保持电脑唤醒」。

同一个 Agent 的预约按列表顺序一条跑完再开下一条，等待中的会写明排在哪一条后面。额度用了不到六成、又不是刚恢复的半小时内，就不再等，每分钟开始一条。你在预约开始的会话里自己接着聊，后面的预约不必等你聊完。

### 分屏：两个会话并排

![会话右键菜单里的「在右侧分屏打开」](assets/guide/split.png)

| 操作 | 方法 |
|---|---|
| 打开分屏 | 右键另一个会话 → **在右侧分屏打开**；或按住 ⌘ 点它；或把它拖到聊天区 |
| 切换焦点 | ⌘1 左侧，⌘2 右侧 |
| 调整宽度 | 拖动中间的分隔线 |
| 收起 / 恢复 | ⌘\ |

两侧可以分别输入、看进度、处理批准。

### 小助手与翻译

![选中文字后的右键菜单](assets/guide/helper.png)

选中回复里的一段，右键：

- **交给小助手**：在右侧打开，用轻量模型和独立上下文解释、追问，不占主会话。
- **翻译**：只翻译选中的这段。回复不是你的语言时，回复下方也会出现 **翻译** 按钮，可以翻整条。

![设置里的「翻译」](assets/guide/translate.png)

| 设置项 | 位置 |
|---|---|
| 翻译成哪种语言、是否自动翻译 | **设置 → 翻译** |
| 翻译用的模型 | [**设置 → 会话 →「轻量任务用的模型」**](conclave:settings/conversation) |

### 还有这些

| 功能 | 怎么用 |
|---|---|
| 待办 | Agent 记下要你之后做的事，在检查器的 **待办** 页签里勾掉 |
| 会话分组 | 侧栏 **会话** 的「分组和排序」，按项目、Agent 或运行状态分组 |
| 关窗不停 | Agent 在后台进程里运行，关掉窗口也不打断 |

随时可以在左下角 **帮助 → 使用指南** 打开本文。
